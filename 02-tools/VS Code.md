## 安装插件
1、中文插件（英文无障碍可跳过）
- 打开扩展，在搜索框搜索**Chinese**
- 选择中文（简体），勾选自动更新，点击"Install"，安装成功后重启VS Code
![alt text](images/image-2.png)
2、Markdown编辑与预览
- 在扩展中搜索**Markdown**，安装**Markdown Preview Enhanced**
- 选择性安装**Markdown All in One**，写 Markdown 时的快捷键和自动化工具集
